# HMM-Guided Hybrid Network Steganography Model

Author: Ishmam Ahmed, UIU
Supervisor: Md. Shohrab Hossain, BUET

## Abstract

The idea is to use HMM in the embedding-section of steganogram by assisting in determining the ratio of embedding capacity btwn covert channels (storage, timing) while a warden oversees the pathway. This study aims to understand:

- How HMM performs in the embedding end of steganography model
- Comparison of HMM with other statistical and analytical models for further evaluation
